API chạy qua index.php — dữ liệu skin đọc từ all-heroes-skins.json (cache tự tạo all-heroes-skins.cache.php khi JSON đổi). Datadome: datadome_params.json — copy cURL POST datadome.garena.com/js/ vào curl.txt rồi python parse_curl.py (hoặc clone từ datadome_params.example.json). Referer/request phải khớp trang bạn bắt curl (Account Center vs SSO login).

Giữa mỗi lần check, server tự chờ tối thiểu ~5s để giảm lỗi Garena error_too_many_requests. Nếu vẫn bị: nghỉ 10–30 phút, check từng acc, hoặc đổi proxy/IP. POST JSON cùng origin; local: php -S localhost:8080 — index.php?page=checker.
